# TGS Tournament Manager

A responsive tournament management web app for Tech Guru Sumit (TGS).

## Planned features

- Create and manage tournaments
- Add players and games
- Automatic knockout fixtures and bracket generation
- Match score updates with automatic winner advancement
- Tournament and player history
- Tournament-wise and player-wise reports
- Responsive dashboard for mobile and desktop
- Persistent data storage

## Project status

Initial project setup. The application will be built in phases with a responsive modern UI and a free-hosting-friendly architecture.
